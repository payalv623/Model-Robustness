What this run makes

13,500 images across the same 10 frozen classes and train/validation/test splits as Color. Group A is 90% nature; Group B is 90% urban. Balanced, reversed, fully conflicting, all-nature and all-urban conditions are included, plus untouched original and neutral-gray controls.

Processing

SAM runs on the Mac GPU through MPS with CPU fallback disabled. The class detector runs on CPU. Source images are read-only; each result has hashes and a resumable record. The worker prevents idle system sleep while running and stops safely if free storage falls below 2 GiB.
